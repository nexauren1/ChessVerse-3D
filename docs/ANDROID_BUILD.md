# Android build notes

- Engine: Godot 4.3 project format.
- Renderer: Compatibility (OpenGL ES 3), selected for broad Android GPU support.
- Orientation: landscape.
- Logical interface canvas: 960 × 540 with expand aspect handling for wider phone displays.
- Input: touchscreen first; mouse input remains useful during editor testing.
- Scene: procedural palace environment, grouped GLB chess assets, metallic materials, and runtime HUD.
- Keep external texture and audio assets small; the current marble pattern is generated by a shader to avoid heavy texture downloads.

## Export
Android export requires the matching Godot export templates and Android build prerequisites configured in the editor. The repository does not yet contain a signed APK or configured export credentials.

## Device testing checklist
- Verify that player panels and side buttons remain readable in landscape on the target phone.
- Confirm that the board fits without being hidden behind the HUD.
- Test sustained frame rate, shadows, glow, reflections, touch accuracy, thermal behaviour, and memory use.
- Reduce reflection probe, light, or skyline complexity if the device struggles.
- Test APK installation and resume behaviour after the first successful export.
